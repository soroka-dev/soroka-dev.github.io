# SorokaDev

Одностраничный адаптивный сайт-визитка студии разработки сайтов и приложений.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не требуются.

## Форма заявок

На странице подготовлена форма заявки с именем, контактом, типом проекта и описанием задачи. Поля и кнопка отправки пока отключены: серверный приём заявок и Telegram-бот будут подключены отдельно. Сайт не передаёт и не сохраняет введённые данные.

Сайт опубликован через GitHub Pages из ветки `main` (корень репозитория).
