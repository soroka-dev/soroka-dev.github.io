# SorokaDev

Одностраничный адаптивный сайт-визитка студии разработки сайтов и приложений.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не требуются.

## Форма заявок

На странице подготовлена форма заявки с именем, контактом, типом проекта и описанием задачи. Клиентская отправка настроена на [Cloudflare Worker](https://github.com/soroka-dev/sorokadev-leads-bot), но поля пока отключены до добавления секретов Telegram-бота в Cloudflare. После проверки отправки нужно убрать `disabled` у `fieldset` в `index.html` и обновить поясняющий текст рядом с формой.

Сайт опубликован через GitHub Pages из ветки `main` (корень репозитория).
