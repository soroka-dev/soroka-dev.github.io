# SorokaDev

Одностраничный адаптивный сайт-визитка студии разработки сайтов и приложений.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не требуются.

## Перед публикацией

Замените ссылку в секции «Есть идея?» на актуальный способ связи (Telegram, почта или форма). Сейчас она ведёт на `github.com/soroka-dev`.

Для GitHub Pages выберите **Settings → Pages → Deploy from a branch → main / (root)**.
